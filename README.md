# C-Language-Lab-Tasks

Task 01: Variable Declaration
Write a C program that declares variables to store the following:
• An integer value
• A float value
• A double value
• A character value
Initialize each variable with a suitable value and display all four values.

Task 02: User Input
Write a C program that asks the user to enter:
• Age
• Height
• Grade
Store each input in an appropriate variable and display the entered values.

Task 03: Shopping Bill
A customer buys products from a store. Write a C program that asks the user to enter one integer
amount and one float amount. Calculate their sum and display the result in float format.

Task 04: Student Marks
A student has marks in three subjects. Write a C program that asks the user to enter the marks of
the three subjects. Calculate and display the total marks and percentage.
Assume each subject is out of 100 marks.

Task 05: Employee Salary
A company records an employee's basic salary and bonus. Write a C program that asks the user to
enter both values, calculates the total salary, and displays the result.
Use appropriate data types for the salary values.
